2. PROJECT OVERVIEW & PROBLEM STATEMENT

Evaluating student assignments manually is labor-intensive and error-prone, 
especially when evaluating large batches of questions with multiple expected 
concepts. This prototype provides an automated AI-assisted evaluation assistant 
combining Computer Vision (EasyOCR) and Natural Language Processing (NLP).

Key Capabilities:
- Pure Pixel-to-Text OCR: Reads student answer-sheet images directly from pixels.
  Extracts Student ID, Question ID, Question, and Student Answer without data leakage.
- Question Identification: Automatically maps extracted question ID (e.g., Q1) 
  and retrieves reference answers and maximum marks from questions.csv.
- NLP Preprocessing: Lowercasing, punctuation cleaning, acronym expansion 
  (AI/Al <-> artificial intelligence, NLP <-> natural language processing, 
  CNN <-> convolutional neural network), tokenization, and lemmatization.
- Hybrid Evaluation Engine:
  * TF-IDF Cosine Similarity (ngram_range=(1,2))
  * Dense Semantic Cosine Similarity (all-MiniLM-L6-v2)
  * Clause-level and sliding-window rubric concept matching against marking_rubric.csv
  * Relevance Gating to filter out completely off-topic or irrelevant answers.
- Constructive Feedback Generation: Lists covered and missing concepts, generating 
  targeted suggestions for answer improvement.
- Faculty Supervision: Interactive override panel for preliminary marks and remarks, 
  with one-click JSON and Markdown report export.


3. COMPONENT-BY-COMPONENT ARCHITECTUREPipeline Flow:
[Answer Image] 
      ↓
[EasyOCR Engine] (detail=1 bounding boxes, vertical line clustering, horizontal sort)
      ↓
[Text Parser] (Student ID normalization, Question ID extraction & recovery fallback)
      ↓
[Reference Retrieval] (Faculty reference answers & max marks from questions.csv)
      ↓
[NLP Preprocessing] (Stopword removal, acronym expansion, lemmatization)
      ↓
[Answer Comparison] (TF-IDF Cosine Sim + all-MiniLM-L6-v2 Semantic Cosine Sim)
      ↓
[Rubric Evaluation] (Clause-level concept matching, RapidFuzz typo tolerance)
      ↓
[Marks Calculation] (Capped strictly at Rubric Weights & Max Marks)
      ↓
[Feedback Engine] (Covered/Missing concepts & natural improvement suggestions)
      ↓
[Faculty Supervision & UI] (Streamlit 3-tab executive interface)

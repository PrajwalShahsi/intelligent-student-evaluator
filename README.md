## 📌 Executive Summary & Problem Statement
Evaluating student assignments manually is a time-consuming and repetitive task for faculty members, particularly in large classes with multi-part questions. 

This prototype provides an **Intelligent Student Assignment Evaluation Assistant** combining:
1. **Computer Vision (OCR):** High-precision text and layout extraction from student answer-sheet images using **EasyOCR**.
2. **Text Parsing & Identification:** Automatic extraction and normalization of `Student ID`, `Question ID`, `Question Text`, and `Student Answer`.
3. **Natural Language Processing (NLP):** Stopword removal, acronym normalization (e.g. `AI` <-> `artificial intelligence`), tokenization, and lemmatization.
4. **Hybrid Grading Engine:** Combining **TF-IDF n-gram cosine similarity**, **Dense Semantic Similarity** (`all-MiniLM-L6-v2`), and **Clause-Level Rubric Matching** against faculty marking rubrics.
5. **Feedback & Supervision:** Meaningful, constructive improvement feedback with a dedicated **Faculty Supervision & Override Panel** and exportable reports in JSON and Markdown formats.

> **⚖️ Supervision Policy:** All marks generated by this system are preliminary and require faculty review before finalizing student scores.

---

## 🛡️ Anti-Leakage & Offline Safety Guarantees
- **Zero Data Leakage:** `student_answers.csv` is strictly isolated to offline benchmarking and the validation dashboard (`validate_pipeline.py`). In live evaluation (`app.py`), answers and IDs are extracted purely from the image pixels via OCR.
- **100% Local Execution:** No paid external LLM APIs (OpenAI/Gemini). Embeddings, OCR, and rubric checks run entirely on local CPU.
- **Crash Prevention:** Handled NLTK resources with safe offline fallbacks and disabled Streamlit file watcher (`.streamlit/config.toml`) to prevent PyTorch runtime crashes.

## 🚀 Setup & Execution Guide

### Prerequisites
- Python 3.11 (Recommended for PyTorch and Windows compatibility)
- Operating System: Windows / Linux / macOS

### 1. Create Virtual Environment & Activate
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 2. Install Dependencies
```powershell
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
```

### 3. Run Automated 24-Image Benchmark
```powershell
python validate_pipeline.py
```

### 4. Launch Streamlit Application
```powershell
streamlit run app.py
```
